# Support

## Where to ask

- **Bugs and feature requests** for any Quirk Systems repository: open an
  issue there using its forms. Organization-level defaults (bug report,
  feature request, repository proposal, brief, decision, agent task) are
  inherited from this repository.
- **Security vulnerabilities**: never a public issue. Follow
  [`SECURITY.md`](SECURITY.md).
- **Conduct concerns**: see [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
- **Questions about doctrine, registries, workflows, or agent instructions**:
  open a `brief` issue in this repository; a question that needs a decision
  becomes a `decision` issue.

## What to include

Exact identities: repository, commit SHA, file paths, the command you ran,
and the observed output. Branch names and screenshots locate a problem; they
do not reproduce it.

## Response expectations

Quirk Systems is operated by a small team. Issues are triaged during the
twice-weekly portfolio review described in
[`docs/governance/AUTONOMOUS_OPERATIONS.md`](docs/governance/AUTONOMOUS_OPERATIONS.md).
Security reports follow the timelines in `SECURITY.md`. There is no
commercial support agreement.
